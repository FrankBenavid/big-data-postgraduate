### Actividad 0. Descargar y verificar antes de leer

Antes de comenzar el taller, activar el entorno, situarse en `kit/` y ejecutar obligatoriamente la preparación y verificación, aunque las muestras ya estén incluidas en el clon:

```bash
python 00_datos.py --listar
python 00_datos.py --descargar pqrs
python 00_datos.py --verificar pqrs
```

El ID `pqrs` agrupa las tres muestras. No descarga los completos de 1,816 GB. Si una muestra ya existe y su hash coincide, se conserva sin descargarla otra vez. Si existe con otra huella, el comando informa el problema y termina con error: conservar ese archivo aparte y revisar su procedencia antes de intentar descargar de nuevo. No se sobrescriben modificaciones locales.

La verificación debe mostrar los tres IDs con estado `coincide` y 1.000 filas por muestra. Usa el separador de cada corte, comprueba 38 columnas, sus nombres y el ancho de los registros. El detalle queda en `kit/salidas/verificacion.json`; otra verificación reemplaza ese informe. `--verificar pqrs` no exige disponer de los datos agroambientales. `--verificar` sin IDs conserva la comprobación de las 12 fuentes agroambientales.

También se puede obtener un solo corte o combinar fuentes:

```bash
python 00_datos.py --descargar pqrs_2024_I
python 00_datos.py --descargar divipola pqrs
```

Después abrir [el notebook P01](../kit/Notebooks/01_Perfil_PQRS.ipynb), declarar la ruta real y leer los CSV con pandas. El descargador prepara los archivos; la inspección, conversión, comparación y verificación del contenido siguen visibles en las celdas del alumno.

**Evidencia:** comando ejecutado, ubicación de los archivos, resultado de verificación y dimensiones observadas en pandas. Esta preparación forma parte del bloque existente, sin agregar una entrega.
