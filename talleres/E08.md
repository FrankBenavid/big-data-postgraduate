## Propósito

Integrar geometrías oficiales y calcular áreas de intersección sin confundir las muestras temáticas con cobertura completa.

## Datos y descarga

D03 MGN departamentos 2025: dane_departamentos.zip, 12.524 MB, completo.

D04 MGN municipios 2025: dane_municipios.zip, 71.576 MB, completo.

D07 Capacidad de uso IGAC: igac_capacidad.json, 0.096 MB, muestra.

D08 Propiedades químicas IGAC: igac_quimica.json, 0.030 MB, muestra.

Con el kit completo ejecutar --verificar. Para obtener una nueva copia utilizar la ruta B del capítulo de descarga y los IDs indicados abajo. Los shapes DANE se descargan por navegador. Todas las URLs están en el catálogo y en fuentes.json.

```
python 00_datos.py --descargar dane_departamentos dane_municipios igac_capacidad igac_quimica
# Para la unión tabular del notebook:
python 00_datos.py --descargar agrosavia divipola
```

## Instrucciones

1. Descargar o verificar los ZIP DANE; comprobar sus componentes y abrir el .prj. La copia suministrada utiliza WGS84.
2. En Jupyter leer departamentos y municipios con GeoPandas. Seleccionar un año y agregar la tabla a una fila por codigo_municipio; unir con mpio_cdpmp como texto de cinco dígitos, validate="one_to_one" y registrar municipios sin correspondencia.
3. Cargar los GeoJSON IGAC. Revisar sus cinco polígonos, atributos de clase y extensión antes de generar un mapa.
4. Ejecutar geografia. El script repara geometrías para la operación, intersecta y calcula áreas en EPSG:9377; conserva los originales y exporta resultados en WGS84.
5. Abrir intersecciones_muestra.geojson, etiquetar “muestra de cinco polígonos por tema” y comparar área calculada con el área original almacenada.

## Ejecución

```
python talleres.py geografia
```

## Entrega y criterios

1.122 geometrías municipales leídas y 15 intersecciones de área positiva en la copia suministrada. Entregar mapa, tabla y explicación del denominador territorial.

## Advertencia de interpretación

El script solo usa las muestras IGAC. No calcular porcentajes de capacidad del municipio completo con ellas. El área del atributo original no cambia automáticamente al recortar. No calcular hectáreas en grados.
