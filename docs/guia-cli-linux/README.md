# Guía de línea de comandos de Linux

[Guía en PDF](Guia_Linea_de_Comandos.pdf) · [Versión HTML](index.html) · [Índice del curso](../../README.md)

Se anexó esta guía como material de apoyo para las personas con poca experiencia en la interfaz de línea de comandos (CLI) de Linux. Su propósito es facilitar la navegación por directorios, la ejecución de comandos y la verificación rápida de archivos durante las actividades del curso.

## Contenido

- Seis escenarios de práctica: preparación del entorno, inspección de archivos, búsqueda y conteo, procesamiento con AWK, verificación de calidad y conservación de resultados.
- Ejemplos de `grep`, `wc`, `awk`, `sort`, `uniq`, `diff` y otras herramientas de consulta.
- Una práctica integradora con resultados de referencia.
- Un cheat sheet de 100 comandos de uso frecuente en Linux, agrupados por finalidad, con opciones habituales y ejemplos.

## Consulta y práctica

El PDF permite consultar o imprimir la guía completa. La versión HTML se abre en un navegador después de clonar o descargar el repositorio; no requiere un servidor ni recursos externos para mostrar el contenido.

El archivo [datos/notas.txt](datos/notas.txt) contiene los datos de práctica. La guía incluye los comandos para reproducirlo en una carpeta independiente llamada `practica-cli`, desde la que se ejecutan los ejemplos. Contiene deliberadamente una nota vacía, una fila repetida y una nota fuera de rango para practicar su detección.

En el curso, la práctica se realiza dentro de Ubuntu sobre WSL, siguiendo la [guía de instalación](../instalacion-wsl.md). Las herramientas de consulta iniciales también se presentan para macOS; el cheat sheet se centra en GNU/Linux y Bash. Algunas herramientas requieren instalación adicional.

Este material complementa la [preparación del entorno](../entorno.md) y la [guía de Git y GitHub](../guia-git/README.md).
